Text Reveal

Words or lines brighten as the block crosses the scrollport. Display type only, never body copy.

Binding scrubbed Mechanism per-word view() timelines Cost low Risk medium — it delays reading

Type that arrives as you reach it, one word at a time.

This is display type only. The same effect on body copy makes the reader wait for the page to permit them to read, which is the fastest way to make a site feel broken.

Each word carries its own view() range, so no JavaScript splits the text at runtime — though the words do have to be wrapped in spans by the template.

Note the resting opacity is .16, not 0. Unrevealed words stay faintly visible, so the shape of the sentence is legible before it resolves and a screen-reader user is never presented with an empty block.

One more, further down.

Scroll back up and the words fade out again — a scrubbed reveal is reversible, which is what keeps it from ever leaving a sentence half-lit.

The craft

Display type only. Editorial rates this ● for pull quotes and display headlines and explicitly never for body copy. A reader who has to scroll to be allowed to read is being obstructed by the design.

Never start at opacity: 0. The resting state here is .16 so the sentence's shape is visible before it resolves. It also means a failed timeline degrades to faint rather than to blank.

Skeuomorphism rates this ✗ on principle — type in that style is printed, engraved or embossed onto a material, so it cannot fade in without contradicting the material it is part of.

Implementation

.tr span{
  opacity: .16;                     /* never 0 — the shape stays legible */
  animation: word auto linear both;
  animation-timeline: view();
  animation-range: entry 24% cover 62%;
}
@keyframes word{ to{ opacity:1 } }

@supports not (animation-timeline: view()){ .tr span{ opacity:1; animation:none } }

When not to use it

  • On body copy. Editorial rates it ● for display and pull quotes only.
  • Starting at opacity:0 — it makes the failure mode a blank block.
  • In skeuomorphism, where type is part of the material and cannot fade in.

Style packs

● for editorial, on pull quotes and display headlines only. ✗ for skeuomorphism — printed and engraved type cannot fade in. Use sparingly everywhere else: it is the technique most likely to be experienced as an obstruction.
