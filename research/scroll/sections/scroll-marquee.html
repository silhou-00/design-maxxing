Scroll Marquee

A ticker that moves with the scroll rather than on a clock. Motion that admits it is motion.

Scroll-bound, not clock-bound. A CSS marquee on an infinite loop runs whether anyone is there or not. This one only moves when you do — which makes it honest about being a response to the reader rather than ambient decoration.

It is also the reason this survives in a pack that bans nearly every other technique. <marquee> was a 1995 HTML element; a scroll-bound ticker is its descendant, and brutalism's whole thesis is that the browser's own history is the material.

REVERSED ◆ SECOND TRACK ◆ OPPOSITE DIRECTION ◆ REVERSED ◆ SECOND TRACK ◆ OPPOSITE DIRECTION ◆ REVERSED

Two tracks running opposite ways is the common pairing. Keep the travel modest — -42% here — because a marquee that outruns its own content shows the gap.

The craft

Duplicate the content, then travel less than half of it. The run must contain enough repeats that translating it never exposes the end. Travelling -42% of a double-length run keeps a full copy on screen at all times.

Scroll-bound beats clock-bound. An infinite CSS loop animates whether or not anyone is looking, costs frames continuously, and has to be collapsed entirely under reduced motion. A scroll-bound marquee stops when the reader stops.

This is brutalism's only ● entry, and that is not an accident: stacking, parallax, video and text reveal are all rated ✗ as polish, while a ticker is machinery.

Implementation

.mq{ overflow: hidden; white-space: nowrap }
.mq .run{
  display: inline-block;             /* transform needs a block box */
  animation: mq auto linear both;
  animation-timeline: scroll(root block);
}
@keyframes mq{ from{ transform:translateX(0) } to{ transform:translateX(-42%) } }

@supports not (animation-timeline: scroll()){ .run{ transform:none; animation:none } }

When not to use it

  • As an infinite clock-bound loop — it burns frames with nobody watching.
  • With travel greater than the duplicated content, which exposes the gap.
  • In minimalism, which rates it ✗: perpetual motion in a style built on stillness.
