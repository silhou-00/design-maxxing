Pinned Scene

A full-bleed stage holds while content passes through it. ONE visual, held — not a sequence of steps.

one stage · held · full bleed

The stage holds. Content passes through it.

This is not the two-column layout scrollytelling uses. The pinned element is the full viewport, and the content scrolls over it.

One visual, unchanged

That is the distinction from scrollytelling. A pinned scene holds a single visual while the page moves past it. Scrollytelling swaps the visual at each step — the visual is the argument's illustration, and it changes as the argument does.

Built from position, nothing else

No timeline, no listener, no library. It holds because its containing block is taller than it is — and it lets go when that block ends.

The craft

How this differs from scrollytelling. A pinned scene holds one visual while content passes; scrollytelling swaps the visual at each step. Same underlying position: sticky, opposite intent — and they should not share a layout, which is why this one is a full-bleed stage rather than a column beside text.

The track must be substantially taller than the pinned element. A composition requirement, not a CSS one, and the commonest reason a pin reads as broken.

Never animate the pinned element itself. GSAP's docs say it plainly — it throws off the measurements. Animate its children.

scroll-state(stuck: top) replaces the listener. Chrome 133+ answers "is it stuck" in CSS, at scroll composition time. Before it, every sticky-shadow effect on the web was a banned scroll listener.

Implementation

.track{ /* the containing block — must be taller than the pin */ }
.pin{ position: sticky; top: 14vh }

/* "has it stuck yet?" — in CSS, no listener. Chrome 133+ */
.bar{ container-type: scroll-state; position: sticky; top: 0 }
@supports (container-type: scroll-state){
  @container scroll-state(stuck: top){
    .bar{ box-shadow: 0 4px 0 0 currentColor }
  }
}

When not to use it

  • When the adjacent column is shorter than the pinned element — the pin will barely hold.
  • With overflow:hidden on any ancestor. It kills sticky. Use overflow-x:clip instead.
  • On mobile, where a pinned element can eat most of a short viewport.

Style packs

● for editorial (a sticky image with text scrolling beside it is a magazine spread), modernism (a composition that assembles itself from square, circle and triangle) and bento (pin the grid, animate the cells' contents). ✗ for neumorphism — a component style has nothing at page scale to pin.
