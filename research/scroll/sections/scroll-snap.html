Scroll Snap

The scroll port comes to rest on defined positions. Native browser behaviour — no timeline, no library, no listener.

Binding native Mechanism scroll-snap-type Cost none Risk medium — it takes control of scroll

One panel at a time

The scroll port rests on each panel. scroll-snap-stop: always means a fast flick cannot skip one.

Native, not animated

No timeline, no library, no listener. This is scroll-snap-type: y mandatory and nothing else.

Which one is snapped?

The inactive panels are dimmed by scroll-state(snapped: y) — in CSS. This was the single most hand-rolled scroll listener on the web.

mandatory vs proximity

mandatory always lands on a snap point. proximity only snaps when you stop nearby, which is far safer for content of varying height.

The craft

This is native behaviour, and that is the whole appeal. It costs nothing, it runs off the main thread by definition, and there is no fallback to write because unsupported browsers simply scroll normally.

mandatory is a commitment. It always lands on a snap point, which means a panel taller than the viewport becomes unreachable in its middle. Use proximity when panel heights vary.

scroll-state(snapped: y) answers "which one is active" in CSS. Chrome 133+. It needs three elements: the scroll container with scroll-snap-type, the target with both scroll-snap-align and container-type: scroll-state, and a child that carries the query. The queried element cannot be the container itself.

Implementation

.snap{ scroll-snap-type: y mandatory; overflow-y: auto; height: 100vh }
.snap > section{
  scroll-snap-align: start;
  scroll-snap-stop: always;          /* a fast flick cannot skip a panel */
  container-type: scroll-state;      /* so a child can ask if it is snapped */
}
@supports (container-type: scroll-state){
  .snap > section .inner{ opacity:.35 }
  @container scroll-state(snapped: y){ .inner{ opacity:1 } }
}

When not to use it

  • With panels taller than the viewport under `mandatory` — their middles become unreachable.
  • On a reading page. Snapping fights reading, which is why editorial rates it ✗.
  • Alongside smooth scroll. Two systems competing for the scroll position is a guaranteed fight.

Style packs

● for modernism — the strongest conceptual match anywhere in the matrix, because the style is built on a module and snap moves in modular steps — plus skeuomorphism (physical controls detent; a dial clicks into position), swiss, flat and neo-brutalism. ⚠ for hand-drawn: snapping is precise and that pack's method is "order first, chaos later". ✗ for editorial — snapping fights reading.
