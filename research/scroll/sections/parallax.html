Parallax

Layers move at different rates to imply depth. The most contradicted technique in the catalogue: seven of the twelve packs ban it outright.

Binding scrubbed Mechanism CSS scroll() timeline on a fixed layer Cost low Risk medium

The backdrop is the effect

The fixed layer behind this panel is the only thing moving. Everything else scrolls normally — which is the whole trick.

Why scroll(), not view()

A backdrop is position: fixed, and a fixed element never enters or leaves the viewport — so view() progress never advances and nothing moves. This is the single most common way a CSS parallax silently does nothing.

Seven packs ban this

Parallax contradicts flat by definition, swiss because layers place elements off-grid every frame, modernism because illusory depth has no structural role, and neumorphism on first principles — one surface colour means there are no layers.

And the pairing that works

Glass over a moving backdrop is the signature pairing in the entire matrix. It is also the most dangerous: backdrop-filter re-blurs every frame. Three glass panels here, and never on a repeating list item.

The craft

A backdrop is fixed, so it needs scroll() and not view(). A fixed element never enters or leaves the viewport, so view-progress never advances — the animation registers, reports running, and moves nothing. This was a live bug in this repo before the audit caught it.

Do not set an explicit animation-range on a scroll() timeline unless you mean it. scroll() already spans the document; writing 0% 100% collapses to a zero-length range and nothing moves.

The moving layer must be behind everything. If a parent paints its own background over the fixed layer, the parallax is hidden behind a static copy of itself.

Implementation

.bg{ position:fixed; inset:-14% 0; z-index:-1 }
.plx{
  animation: px auto linear both;
  animation-timeline: scroll(root block);   /* NOT view() — a fixed layer never enters */
}
@keyframes px{
  from{ transform: translateY(-8%) scale(1.16) }
  to  { transform: translateY( 8%) scale(1.16) }
}
@supports not (animation-timeline: scroll()){ .plx{ transform:none; animation:none } }

When not to use it

  • Any pack that bans depth — flat, swiss, modernism, neumorphism, bento, brutalism, minimalism.
  • On a repeating scroll item behind glass. backdrop-filter re-blurs every frame; that is the documented FPS killer.
  • Without the scale(). A translated backdrop reveals its own edges unless it is oversized.
