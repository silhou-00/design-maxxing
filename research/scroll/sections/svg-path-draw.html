SVG Path Draw

A line draws itself as you scroll. The one technique that legitimately animates stroke-dashoffset.

Binding scrubbed Mechanism stroke-dashoffset on a view() timeline Cost low Risk low

pathLength="1" is the trick

It normalises the path so stroke-dashoffset runs cleanly from 1 to 0, with no one computing a real path length in JavaScript.

Several paths, one range

Each path carries its own pathLength, so they draw together regardless of how different their real lengths are.

The one legitimate exception

stroke-dashoffset is on engine §6's banned list because it forces paint. This is the technique that cannot exist without it — so it is exempted explicitly, and the audit records the exemption rather than hiding it.

The craft

pathLength="1" is the whole trick. It normalises any path to a length of 1, so stroke-dasharray: 1; stroke-dashoffset: 1 works on every path in a drawing without measuring a single one. Without it you need path.getTotalLength() in JavaScript.

This technique is the exception to §6's composite-only rule. stroke-dashoffset forces paint on every frame — it is on the banned list by name. The exemption is declared in the section's data-composite-exempt, so the audit reports it as a known exception rather than silently passing it.

Paint cost scales with stroke complexity. A handful of simple paths is fine; a detailed illustration re-rasterises every frame.

Implementation

<path d="…" pathLength="1"/>     <!-- normalise, so no JS measuring -->

.draw path{
  fill: none;
  stroke-dasharray: 1;
  stroke-dashoffset: 1;
  animation: dw auto linear both;
  animation-timeline: view();
  animation-range: entry 5% cover 55%;
}
@keyframes dw{ to{ stroke-dashoffset: 0 } }

@supports not (animation-timeline: view()){
  .draw path{ stroke-dashoffset:0; animation:none }
}

When not to use it

  • On a detailed illustration. Every frame re-rasterises the stroke.
  • For content that must be readable. A half-drawn line is not information.
  • Without pathLength — otherwise every path needs measuring in JavaScript.
