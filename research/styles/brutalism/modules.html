Brutalism — Module Sheet

Show the bones. The browser's honest defaults are the palette, and comfort is not a goal. Eight modules, five button states, dark mode and narrow width — every value read from tokens.json. This page is the proof; style.md and modules.md are the spec.

Token strip tokens.json

The honesty test: if a rule exists only to make the page more comfortable, delete it. Rounded corners, easing, hover fades, blurred shadows, tidy gutters — all out. But note what that leaves IN: raw saturated colour fields, enormous type, hard-edged texture and collage. Brutalism is loud on purpose — it is not the absence of design.

Banned the pack's hard filter

A pack's ## banned list outranks any vendor skill. These are mechanically checked where a browser can see them; the rest still need eyes.

  • border-radius above 0
  • blurred shadows — hard-offset with 0 blur is fine
  • transitions and easing on interaction states
  • a tidy, consistent gutter
  • muted or 'tasteful' colour — this pack is required to be loud
  • soft gradient fades (hard-edged stripe and halftone texture is fine)
  • stock photography, illustration systems, icon sets
  • centred layouts
