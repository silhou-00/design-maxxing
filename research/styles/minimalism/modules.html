Minimalism — Module Sheet

The fewest elements that do the job. Everything left on the page has to justify being there. Eight modules, five button states, dark mode and narrow width — every value read from tokens.json. This page is the proof; style.md and modules.md are the spec.

Token strip tokens.json

Rams #10, and the pack's whole thesis: “Good design is as little design as possible.” This is a spacing and restraint system, not a decoration system.

Rendered on purpose. The audit excludes .bad stages — a deliberate violation is a lesson, not a defect.

Banned the pack's hard filter

A pack's ## banned list outranks any vendor skill. These are mechanically checked where a browser can see them; the rest still need eyes.

  • a second accent colour
  • decorative dividers, badges, ribbons, gradient fills
  • drop shadows used to separate things that spacing could separate
  • icons next to labels that already say the same thing
  • more than two type sizes in a section
  • filling whitespace because it looks empty — that is the style working
