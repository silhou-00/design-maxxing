Bento — Module Sheet

Every piece of content in its own rounded compartment. Tight gaps, varied cell spans, no empty space. Eight modules, five button states, dark mode and narrow width — every value read from tokens.json. This page is the proof; style.md and modules.md are the spec.

Token strip tokens.json

Bento is a CSS Grid pattern with a span vocabulary. The design work is deciding which cells span. Four numbers carry it: 4 columns, 74px rows, 10px gap, 18px radius.

Colour

--page
#0d0d0f · the ground the grid sits on

--cell
#1a1a1f · one step off the page — never the same value

--hairline
#2a2a31 · 1px border, one step lighter than the fill. Load-bearing on dark

--text
#f5f5f7 · the value in a cell

--muted
#a1a1aa · the label under the value

--accent
#4ade80 · ONE hue across the whole grid, and it lives in the data

4 · Form field + error label, focus, and error without colour alone

An input is a cell with a darker fill. The error state cannot use a red border alone (colour-only signalling, WCAG 1.4.1) and cannot use a heavy shadow, so it uses a filled label row inside the cell.

8 · Empty / loading 0 of 12 packs specified one

An empty cell is the one thing this pack bans outright — Tilda: no empty filler cells to make the grid resolve. So an empty state is a cell with a dashed hairline that states what is missing, never a blank compartment.

Dark mode 0 of 12 packs specified one

Banned the pack's hard filter

A pack's ## banned list outranks any vendor skill. These are mechanically checked where a browser can see them; the rest still need eyes.

  • wide gaps - Tilda: 'very little empty space'
  • uniform cell sizes - no span variation
  • sharp corners
  • heavy shadows - the hairline border replaces them
  • decorative treatment inside cells
  • more than one accent hue across the whole grid
  • empty filler cells to make the grid resolve
