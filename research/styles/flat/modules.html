Flat — Module Sheet

Zero depth. Colour and type do all the work, and every state is carried by fill. Eight modules, five button states, dark mode and narrow width — every value read from tokens.json. This page is the proof; style.md and modules.md are the spec.

no shadow · no gradient · 4px radius · two-step colour ramp  ·  source: Tilda + Looka + NN/g

Token strip tokens.json

Because there is no depth, state must be carried by fill. Every interactive colour needs a two-step ramp — base and pressed — derived against the text size it will carry. #2f7fb8 looks like a fine flat blue and clears large text at 4.33:1, but fails 14px body; it is demoted here to a non-text tint. And note the palette is wide on purpose: flat is the one pack here that runs 5–8 hues.

Banned the pack's hard filter

A pack's ## banned list outranks any vendor skill. These are mechanically checked where a browser can see them; the rest still need eyes.

  • box-shadow of any kind
  • linear-gradient / radial-gradient
  • bevels, insets, glossy highlights
  • text-shadow
  • faux-3D icons or illustrations
  • depth-based elevation systems — that is Material, not flat
