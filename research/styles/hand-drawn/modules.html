Hand-Drawn — Module Sheet

Token strip tokens.json

Tilda's method as a procedure: lay out on a real grid with real alignment, then rotate each element by a different value between −2° and +2°, replace box radii with the wobble syntax, add two or three hand marks, and stop. The restraint is what keeps it charming rather than broken.

Banned the pack's hard filter

A pack's ## banned list outranks any vendor skill. These are mechanically checked where a browser can see them; the rest still need eyes.

  • script or handwriting fonts in body copy
  • rotations above ±3° — reads as broken layout, not hand-made
  • the SAME rotation on every element — it reveals the trick instantly
  • uniform border-radius
  • drop shadows and soft gradients
  • fully random placement with no underlying grid — order first, chaos later
  • stock doodle packs — custom marks are the entire differentiator
  • a dense layout — white space is half the style
